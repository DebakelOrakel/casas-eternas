# Changelog — Concepts

Setting & world concepts — the peoples, factions, and game-fiction ideas. Distinct from
[mechanics.md](./mechanics.md) (how the game plays) and from the decision records in
[docs/decisions/](../decisions/) (when a technical fork was resolved). Source material lives in
`docs/ideas/` and `docs/vision.md`.

## 2026-07-28
- **changed** Species: the three peoples are **species**, not "races" — human, dwarf, beaver. Settled with the i18n namespace (`world.species.*`); the code identifiers are renamed separately later. `world.species`

## 2026-07-26
- **new** Anthropology: ecology → anthropology concept — a world's peoples emerge from its resource geography (carrying capacity → subsistence/material/prestige → dispersal). See [docs/decisions/ecology.md](../decisions/ecology.md).

## 2026-07-20
- **new** Vision: game-concept ideas captured — a civ/trade dynasty simulation on a plausibly-generated world; three species; the "three breaches".
